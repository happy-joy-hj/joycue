# JoyCue

JoyCue is a lightweight recommendation tool that helps people find realistic things they can do right now based on their available time, energy, environment, interests, and other context.

Instead of creating another productivity system or overwhelming users with long task lists, JoyCue focuses on one question:

> What can I do right now?

## Project Status

🚧 JoyCue is currently under active development.

## Tech Stack

### Web Application

- Next.js
- TypeScript
- Tailwind CSS

### Recommendation Service

- Python
- FastAPI
- Pydantic
- pytest
